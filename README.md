# Fosholer-daktar-UI

Mobile-first chatbot UI for the [ফসলের ডাক্তার](https://github.com/rifayetrimon/Fosholer-daktar-UI) crop disease detection system.

## Features
- Login page with JWT authentication
- Mobile-responsive chat interface
- 📷 Leaf image upload → AI disease detection
- Bangla quick-ask chips for common crop diseases
- Dark mode support

## Usage
1. Make sure the backend is running at `http://localhost:8000`
2. Open `index.html` in your browser
3. Login with your credentials

## Backend
Connects to the [fosholer-daktar](https://github.com/rifayetrimon) FastAPI backend.
